## Description (EN)
```
⭐ One tap to play! Merge matching stars into bigger ones.

Star Drop is a puzzle game where you drop numbered stars into columns. When matching numbers touch, they merge and double. Watch one drop set off a chain reaction!

• Simple one-hand controls — perfect for quick breaks
• Chain combos — one move, multiple satisfying merges
• Daily Challenge — everyone gets the same sequence each day. Compare scores with friends
• Streaks — come back daily and keep your streak alive
• Hammer & Swap tools for tricky moments
• Play offline, no data collected

Faster than 2048, easier than Tetris. Start dropping stars now! 🌠
```
