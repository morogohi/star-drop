# 🌠 STAR DROP (스타 드롭)

드롭 + 머지 퍼즐 게임. Capacitor 8 기반으로 Android / iOS 앱을 함께 빌드합니다.

- 게임 소스: `www/index.html`
- 배포 가이드: **[DEPLOY.md](DEPLOY.md)**
- 스토어 등록 자료: `store/`
- 성장 계획(CPI·리텐션·수익화·퍼블리셔): **[GROWTH.md](GROWTH.md)** · 광고 소재: `ads/`

```bash
npm ci && npx cap sync
npx cap open android   # Android Studio
npx cap open ios       # Xcode (Mac)
```
